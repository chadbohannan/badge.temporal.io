# Third-Party Licensing Inside an MIT Repo

The repository is MIT-licensed by default (`LICENSE`), but `THIRD_PARTY_NOTICES.md` carves out a few pieces that aren't. Two [Community Apps](../components/community-apps-registry.md) — Durable Snake and Starfield Nametag, both by Alexandre Roman, imported from his separate `temporal-replay-2026-badge-apps` repository — carry Apache License 2.0 terms (`licenses/Apache-2.0.txt`) rather than this repo's MIT default, so their Apache notices need preserving on redistribution. A third Community App, Tardigotchi by aask42, and the public event photo `docs/assets/photos/replay-badge-table.jpg`, are also called out individually: the photo is documentation content, not source, and isn't covered by the MIT license either.

`THIRD_PARTY_NOTICES.md` says outright that it "should be expanded as the firmware import is completed and the exact vendored dependency set is finalized" — MicroPython, Arduino/ESP32/PlatformIO libraries, QR utilities, U8g2, ArduinoJson, and Adafruit/SparkFun libraries are named as known-but-not-yet-fully-enumerated dependencies with their own upstream license notices to preserve.

**Until 2026-09-17, this page's central claim was different**: firmware binaries built with the now-removed [Doom port](../components/doom.md) bundled GPL-2.0-or-later DoomGeneric engine source, which made a Doom-enabled build not MIT-only, plus separately-licensed `doom1.wad` shareware game data owned by id Software. Both the GPL and WAD license files (`licenses/GPL-2.0.txt`, `licenses/DOOM1-WAD.txt`) were deleted along with the Doom port itself, so every `replay2026` build is MIT-only again except for the Apache-licensed Community Apps above.
