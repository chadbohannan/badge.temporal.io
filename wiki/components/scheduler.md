# The Cooperative Scheduler

`firmware/src/infra/Scheduler.{h,cpp}` is the generic backbone that lets the badge run many independent subsystems on Core 1 without giving each one its own FreeRTOS task. Anything that needs periodic attention — [`WiFiService`](../systems/replay2026-firmware.md), `ota::OTAService` (see [OTA and assets](ota-and-assets.md)), `ConfigWatcher`, `FileBrowser`, [`LEDAppRuntime`](led-app-runtime.md) — implements the two-method `IService` interface (`service()` plus a `name()` for `printTasks()` diagnostics) and registers with the single process-wide `Scheduler` at one of three priorities (`kHigh`/`kNormal`/`kLow`, up to `kMaxServices = 16` total).

`runFor(budgetMs)` is what the Arduino `loop()` actually calls each pass: it walks the registered services in priority order, but a per-priority execution divisor (set via `setExecutionDivisors()`) means low-priority services only get serviced on a fraction of loop iterations rather than every single one, so an expensive-but-infrequent service can't starve time-critical ones just by being registered. `setServiceState()` lets a service be temporarily disabled by name or pointer without unregistering it — this is how, for example, the [Doom app-mode takeover](doom.md) suspends the GUI/OLED/LED/IMU/battery/config services for the duration of a game session and then flips them all back on at exit, rather than the Doom code needing direct knowledge of each service's internals.

This scheduler is deliberately a different mechanism from the [MicroPython cooperative pump](micropython-bridge.md)'s `mpy_service_pump()` — the Scheduler runs native C++ `IService`s on every `loop()` pass regardless of what Python is doing, while `mpy_service_pump()` is specifically what keeps *those same* underlying services (inputs, OLED/LED ownership, IMU, haptics) responsive during the interval where a foreground MicroPython app has blocked Core 1 in a `time.sleep()` or polling call. Both exist because the firmware has no general-purpose task-per-subsystem model; native services cooperate through the Scheduler, and MicroPython apps cooperate with those same native services through the pump.
